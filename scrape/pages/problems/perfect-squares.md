## What we know

Example 1

```
Input: n = 12
Output: 3
```

12 = 4 + 4 + 4.

Example 2

```
Input: n = 13
Output: 2
```

13 = 4 + 9.

## Constraints

* •

  `1 <= n <= 10^4`
* •

  The answer is at most 4 by Lagrange's four-square theorem.
