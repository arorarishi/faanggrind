## What we know

Example 1

```
Input: nums = [7,2,5,10,8], k = 2
Output: 18
```


## Constraints

* •

  `1 <= nums.length <= 1000`
* •

  `0 <= nums[i] <= 10^6`
* •

  `1 <= k <= min(50, nums.length)`
