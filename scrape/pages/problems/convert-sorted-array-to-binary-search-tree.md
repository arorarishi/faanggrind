## What we know

Example 1

```
Input: nums = [-10,-3,0,5,9]
Output: [0,-3,9,-10,null,5]
```

[0,-10,5,null,-3,null,9] is also accepted.

Example 2

```
Input: nums = [1,3]
Output: [3,1]
```

## Constraints

* •

  `1 <= nums.length <= 10^4`
* •

  `-10^4 <= nums[i] <= 10^4`
* •

  `nums` is sorted in a strictly increasing order.
