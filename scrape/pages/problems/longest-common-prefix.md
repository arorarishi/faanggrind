Example 1

```
Input: strs = ["flower","flow","flight"]
```

```
Input: strs = ["dog","racecar","car"]

```

No common prefix exists.

## Constraints

* •

  `1 <= strs.length <= 200`
* •

  `0 <= strs[i].length <= 200`
* •

  `strs[i]` consists of only lowercase English letters if non-empty.
