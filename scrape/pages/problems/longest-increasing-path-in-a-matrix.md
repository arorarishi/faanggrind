## What we know

Example 1

```
Input: matrix = [[9,9,4],[6,6,8],[2,1,1]]
Output: 4
```

The path 1 -> 2 -> 6 -> 9.

Example 2

```
Input: matrix = [[3,4,5],[3,2,6],[2,2,1]]
Output: 4
```

The path 3 -> 4 -> 5 -> 6.

Example 3

```
Input: matrix = [[1]]
Output: 1
```

## Constraints

* •

  `m == matrix.length`
* •

  `n == matrix[i].length`
* •

  `1 <= m, n <= 200`
* •

  `0 <= matrix[i][j] <= 2^31 - 1`
