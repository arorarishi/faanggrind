```

24 from list 1, 20 from list 2, 22 from list 3.

Input: nums = [[1,2,3],[1,2,3],[1,2,3]]

```

## Constraints

* •

  `nums.length == k`
* •

  `1 <= k <= 3500`
* •

  `1 <= nums[i].length <= 50`
* •

  `-10^5 <= nums[i][j] <= 10^5`
* •

  `nums[i]` is sorted in non-decreasing order.
