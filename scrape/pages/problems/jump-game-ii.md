## What we know

Example 1

```
Input: nums = [2,3,1,1,4]
Output: 2
```

Jump 1 step to index 1, then 3 steps to the end.

Example 2

```
Input: nums = [2,3,0,1,4]
Output: 2
```

## Constraints

* •

  `1 <= nums.length <= 10^4`
* •

  `0 <= nums[i] <= 1000`
* •

  It is guaranteed that you can reach `nums[n - 1]`.
