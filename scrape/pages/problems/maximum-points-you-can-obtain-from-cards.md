## What we know

Example 1

```
Input: cardPoints = [1,2,3,4,5,6,1], k = 3
Output: 12
```

Take the three rightmost cards 1, 6 and 5 for a total of 12.

Example 2

```
Input: cardPoints = [2,2,2], k = 2
Output: 4
```

Example 3

```
Input: cardPoints = [9,7,7,9,7,7,9], k = 7
Output: 55
```

## Constraints

* •

  `1 <= cardPoints.length <= 10^5`
* •

  `1 <= cardPoints[i] <= 10^4`
* •

  `1 <= k <= cardPoints.length`
