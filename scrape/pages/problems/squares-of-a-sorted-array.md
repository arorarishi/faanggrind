## What we know

Example 1

```
Input: nums = [-4,-1,0,3,10]
Output: [0,1,9,16,100]
```

Example 2

```
Input: nums = [-7,-3,2,3,11]
Output: [4,9,9,49,121]
```

## Constraints

* •

  `1 <= nums.length <= 10^4`
* •

  `-10^4 <= nums[i] <= 10^4`
* •

  `nums` is sorted in non-decreasing order.
