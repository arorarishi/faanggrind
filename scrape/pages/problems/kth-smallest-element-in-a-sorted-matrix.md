```

Sorted: 1,5,9,10,11,12,13,13,15; the 8th is 13.

```

## Constraints

* •

  `n == matrix.length == matrix[i].length`
* •

  `1 <= n <= 300`
* •

  `-10^9 <= matrix[i][j] <= 10^9`
* •

  `1 <= k <= n^2`
