## What we know

Example 1

```
Input: words = ["abcd","dcba","lls","s","sssll"]
Output: [[0,1],[1,0],[3,2],[2,4]]
```

The palindromes are "abcddcba", "dcbaabcd", "slls", "llssssll".

Example 2

```
Input: words = ["bat","tab","cat"]
Output: [[0,1],[1,0]]
```

Example 3

```
Input: words = ["a",""]
Output: [[0,1],[1,0]]
```

## Constraints

* •

  `1 <= words.length <= 5000`
* •

  `0 <= words[i].length <= 300`
* •

  `words[i]` consists of lowercase English letters.
