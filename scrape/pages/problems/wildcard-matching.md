## What we know

Example 1

```
Input: s = "aa", p = "a"
Output: false
```

Example 2

```
Input: s = "aa", p = "*"
Output: true
```

Example 3

```
Input: s = "cb", p = "?a"
Output: false
```

'?' matches 'c' but 'a' does not match 'b'.

## Constraints

* •

  `0 <= s.length, p.length <= 2000`
* •

  `s` contains only lowercase letters.
* •

  `p` contains lowercase letters, '?' or '\*'.
