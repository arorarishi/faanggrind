## What we know

Example 1

```
Input: nums = [1,2,3,4]
Output: [24,12,8,6]
```

Example 2

```
Input: nums = [-1,1,0,-3,3]
Output: [0,0,9,0,0]
```

## Constraints

* •

  `2 <= nums.length <= 10^5`
* •

  `-30 <= nums[i] <= 30`
* •

  The product of any prefix or suffix of `nums` fits in a 32-bit integer.
