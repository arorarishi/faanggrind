## What we know

Example 1

```
Input: s = "()())()"
Output: ["(())()","()()()"]
```

Example 2

```
Input: s = "(a)())()"
Output: ["(a())()","(a)()()"]
```

Example 3

```
Input: s = ")("
Output: [""]
```

## Constraints

* •

  `1 <= s.length <= 25`
* •

  `s` consists of lowercase English letters and parentheses '(' and ')'.
* •

  There will be at most 20 parentheses in `s`.
