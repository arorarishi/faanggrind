## What we know

Example 1

```
Input: s = "tree"
Output: "eert"
```

"eetr" is also valid.

Example 2

```
Input: s = "cccaaa"
Output: "aaaccc"
```

Example 3

```
Input: s = "Aabb"
Output: "bbAa"
```

## Constraints

* •

  `1 <= s.length <= 5 * 10^5`
* •

  `s` consists of uppercase and lowercase English letters and digits.
