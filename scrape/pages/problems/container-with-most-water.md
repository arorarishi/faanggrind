## What we know

Example 1

```
Input: height = [1,8,6,2,5,4,8,3,7]
Output: 49
```

Lines at index 1 and 8 (heights 8 and 7) give min(8,7) \* (8-1) = 49.

Example 2

```
Input: height = [1,1]
Output: 1
```

## Constraints

* •

  `n == height.length`
* •

  `2 <= n <= 10^5`
* •

  `0 <= height[i] <= 10^4`
