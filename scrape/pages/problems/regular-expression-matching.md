## What we know

Example 1

```
Input: s = "aa", p = "a"
Output: false
```

Example 2

```
Input: s = "aa", p = "a*"
Output: true
```

'\*' lets 'a' repeat, so "a\*" can match "aa".

Example 3

```
Input: s = "ab", p = ".*"
Output: true
```

".\*" means zero or more of any character.

## Constraints

* •

  `1 <= s.length <= 20`
* •

  `1 <= p.length <= 20`
* •

  `s` contains only lowercase letters; `p` contains lowercase letters, '.' and '\*'.
* •

  Every '\*' is preceded by a valid character.
