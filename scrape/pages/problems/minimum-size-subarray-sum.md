## What we know

Example 1

```
Input: target = 7, nums = [2,3,1,2,4,3]
Output: 2
```

The subarray [4,3] has the minimal length.

Example 2

```
Input: target = 4, nums = [1,4,4]
Output: 1
```

Example 3

```
Input: target = 11, nums = [1,1,1,1,1,1,1,1]
Output: 0
```

## Constraints

* •

  `1 <= target <= 10^9`
* •

  `1 <= nums.length <= 10^5`
* •

  `1 <= nums[i] <= 10^4`
