## What we know

Example 1

```

```

Example 2

```
Input: matrix = [["0","1"],["1","0"]]

```

Example 3

```
Input: matrix = [["0"]]
Output: 0
```

## Constraints

* •

  `m == matrix.length`
* •

  `n == matrix[i].length`
* •

  `1 <= m, n <= 300`
* •

  `matrix[i][j]` is '0' or '1'.
