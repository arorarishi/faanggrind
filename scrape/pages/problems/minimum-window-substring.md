## What we know

Example 1

```
Input: s = "ADOBECODEBANC", t = "ABC"
Output: "BANC"
```

Example 2

```
Input: s = "a", t = "a"
Output: "a"
```

Example 3

```
Input: s = "a", t = "aa"
Output: ""
```

Both 'a's from t must be in the window; s has only one.

## Constraints

* •

  `m == s.length`
* •

  `n == t.length`
* •

  `1 <= m, n <= 10^5`
* •

  `s` and `t` consist of uppercase and lowercase English letters.
