## What we know

Example 1

```
Input: n = 7, cuts = [1,3,4,5]
Output: 16
```

Cutting in the order [3, 5, 1, 4] costs 7 + 4 + 3 + 2 = 16.

Example 2

```
Input: n = 9, cuts = [5,6,1,4,2]
Output: 22
```

## Constraints

* •

  `2 <= n <= 10^6`
* •

  `1 <= cuts.length <= min(n - 1, 100)`
* •

  `1 <= cuts[i] <= n - 1`
* •

  All the integers in `cuts` array are distinct.
