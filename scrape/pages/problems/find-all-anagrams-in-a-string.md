## What we know

Example 1

```
Input: s = "cbaebabacd", p = "abc"
Output: [0,6]
```

"cba" and "bac" are anagrams of "abc".

Example 2

```
Input: s = "abab", p = "ab"
Output: [0,1,2]
```

## Constraints

* •

  `1 <= s.length, p.length <= 3 * 10^4`
* •

  `s` and `p` consist of lowercase English letters.
