## What we know

Example 1

```
Input: nums = [3,4,5,1,2]
Output: 1
```

The original array [1,2,3,4,5] was rotated 3 times.

Example 2

```
Input: nums = [4,5,6,7,0,1,2]
Output: 0
```

Example 3

```
Input: nums = [11,13,15,17]
Output: 11
```

## Constraints

* •

  `n == nums.length`
* •

  `1 <= n <= 5000`
* •

  `-5000 <= nums[i] <= 5000`
* •

  All the integers of `nums` are unique.
