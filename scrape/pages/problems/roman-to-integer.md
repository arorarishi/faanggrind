## What we know

Example 1

```
Input: s = "III"
Output: 3
```

Example 2

```
Input: s = "LVIII"
Output: 58
```

L = 50, V = 5, III = 3.

Example 3

```
Input: s = "MCMXCIV"
Output: 1994
```

M = 1000, CM = 900, XC = 90, IV = 4.

## Constraints

* •

  `1 <= s.length <= 15`
* •

  `s` contains only the characters I, V, X, L, C, D, M.
* •

  `s` is a valid Roman numeral in the range `[1, 3999]`.
