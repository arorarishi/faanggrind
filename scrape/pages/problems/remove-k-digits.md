## What we know

Example 1

```
Input: num = "1432219", k = 3
Output: "1219"
```

Example 2

```
Input: num = "10200", k = 1
Output: "200"
```

Remove the leading 1 and drop the leading zeros.

Example 3

```
Input: num = "10", k = 2
Output: "0"
```

## Constraints

* •

  `1 <= k <= num.length <= 10^5`
* •

  `num` consists of only digits.
* •

  `num` does not have any leading zeros except for the zero itself.
