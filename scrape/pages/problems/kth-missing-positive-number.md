## What we know

Example 1

```
Input: arr = [2,3,4,7,11], k = 5
Output: 9
```

Missing: 1, 5, 6, 8, 9, 10, 12, ... The 5th is 9.

Example 2

```
Input: arr = [1,2,3,4], k = 2
Output: 6
```

## Constraints

* •

  `1 <= arr.length <= 1000`
* •

  `1 <= arr[i] <= 1000`
* •

  `1 <= k <= 1000`
* •

  `arr[i] < arr[j]` for `1 <= i < j <= arr.length`
