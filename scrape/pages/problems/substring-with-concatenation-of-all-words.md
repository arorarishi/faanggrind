## What we know

Example 1

```
Input: s = "barfoothefoobarman", words = ["foo","bar"]
Output: [0,9]
```

"barfoo" starts at 0 and "foobar" starts at 9.

Example 2

```
Input: s = "wordgoodgoodgoodbestword", words = ["word","good","best","word"]
Output: []
```

## Constraints

* •

  `1 <= s.length <= 10^4`
* •

  `1 <= words.length <= 5000`
* •

  `1 <= words[i].length <= 30`
* •

  All words have the same length.
