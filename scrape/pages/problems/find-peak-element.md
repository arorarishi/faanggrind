## What we know

Example 1

```
Input: nums = [1,2,3,1]
Output: 2
```

3 is a peak.

Example 2

```
Input: nums = [1,2,1,3,5,6,4]
Output: 5
```

Index 1 (value 2) is also a valid peak.

## Constraints

* •

  `1 <= nums.length <= 1000`
* •

  `-2^31 <= nums[i] <= 2^31 - 1`
* •

  `nums[i] != nums[i + 1]` for all valid i.
