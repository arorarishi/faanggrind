## What we know

Example 1

```
Input: s = "ab#c", t = "ad#c"
Output: true
```

Both become "ac".

Example 2

```
Input: s = "ab##", t = "c#d#"
Output: true
```

Both become "".

Example 3

```
Input: s = "a#c", t = "b"
Output: false
```

## Constraints

* •

  `1 <= s.length, t.length <= 200`
* •

  `s` and `t` only contain lowercase letters and '#' characters.
