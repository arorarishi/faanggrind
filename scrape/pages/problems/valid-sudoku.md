## What we know

Example 1

```
Input: board = [["5","3",".",".","7",".",".",".","."],["6",".",".","1","9","5",".",".","."],[".","9","8",".",".",".",".","6","."],["8",".",".",".","6",".",".",".","3"],["4",".",".","8",".","3",".",".","1"],["7",".",".",".","2",".",".",".","6"],[".","6",".",".",".",".","2","8","."],[".",".",".","4","1","9",".",".","5"],[".",".",".",".","8",".",".","7","9"]]
Output: true
```

Example 2

```
Input: Same board but with board[0][0] changed from "5" to "8"
Output: false
```

Two 8s now appear in the top-left 3 x 3 box.

## Constraints

* •

  `board.length == 9`
* •

  `board[i].length == 9`
* •

  `board[i][j]` is a digit 1-9 or '.'.
