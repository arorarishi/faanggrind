## What we know

Example 1

```
Input: tokens = ["2","1","+","3","*"]
Output: 9
```

((2 + 1) \* 3) = 9.

Example 2

```
Input: tokens = ["4","13","5","/","+"]
Output: 6
```

(4 + (13 / 5)) = 6.

Example 3

```
Input: tokens = ["10","6","9","3","+","-11","*","/","*","17","+","5","+"]
Output: 22
```

## Constraints

* •

  `1 <= tokens.length <= 10^4`
* •

  `tokens[i]` is an operator or an integer in the range `[-200, 200]`.
