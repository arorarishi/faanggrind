## What we know

Example 1

```

```

```
Input: ratings = [1,2,2]
```

## Constraints

* •

  `n == ratings.length`
* •

  `1 <= n <= 2 * 10^4`
* •

  `0 <= ratings[i] <= 2 * 10^4`
