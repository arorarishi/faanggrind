## What we know

Example 1

```
Input: nums = [1,1,1,2,2,3], k = 2
Output: [1,2]
```

Example 2

```
Input: nums = [1], k = 1

```

## Constraints

* •

  `1 <= nums.length <= 10^5`
* •

  `-10^4 <= nums[i] <= 10^4`
* •

  `k` is in the range `[1, number of unique elements]`.
