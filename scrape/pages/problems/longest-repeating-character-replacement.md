## What we know

Example 1

```
Input: s = "ABAB", k = 2
Output: 4
```

Replace both A's with B's (or vice versa).

Example 2

```
Input: s = "AABABBA", k = 1
Output: 4
```

Replace the middle A to get "AABBBBA"; the substring "BBBB" has length 4.

## Constraints

* •

  `1 <= s.length <= 10^5`
* •

  `s` consists of only uppercase English letters.
* •

  `0 <= k <= s.length`
