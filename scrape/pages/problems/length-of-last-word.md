## What we know

Example 1

```
Input: s = "Hello World"
Output: 5
```

Example 2

```
Input: s = "   fly me   to   the moon  "
Output: 4
```

The last word is "moon".

Example 3

```
Input: s = "luffy is still joyboy"
Output: 6
```

## Constraints

* •

  `1 <= s.length <= 10^4`
* •

  `s` consists of only English letters and spaces.
* •

  There is at least one word in `s`.
