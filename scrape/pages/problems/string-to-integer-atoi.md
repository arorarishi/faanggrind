## What we know

Example 1

```
Input: s = "42"
Output: 42
```

Example 2

```
Input: s = "   -042"
Output: -42
```

Whitespace is skipped, the sign is read, leading zeros are dropped.

Example 3

```
Input: s = "1337c0d3"
Output: 1337
```

Reading stops at the first non-digit.

## Constraints

* •

  `0 <= s.length <= 200`
* •

  `s` consists of English letters, digits, ' ', '+', '-', and '.'.
